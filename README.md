# ManageBot — Discord 服务器管理机器人

一个用 **TypeScript + discord.js v14** 编写的模块化 Discord 管理机器人。

它目前的核心功能是**募选**：帮社区把「招募管理/职位选举」这件事完全自动化——管理员发起一个空位，候选人点按钮自荐，到点自动开启投票（支持大众投票和管理内部投票双轨制），再到点自动计票、按权重排名、公示当选名单。全程不需要人工盯着。

同时项目保留了一套干净的**模块化骨架**：想加新功能时，复制模板模块照着写即可，不用动核心代码。

## 功能一览

### 🗳️ 募选模块（核心功能）

- **完整选举流程**：发起 → 自荐 → 投票 → 结算 → 公示，到点自动推进，也可随时手动干预。
- **双轨投票**：大众投票（面向普通成员）和管理内部投票（面向管理组）可分别开关，按可配置的权重合并计票。
- **候选池管理**：只有「候选池」里的人才能自荐。候选池支持三种来源：
  1. 外部 API 自动同步（可定时轮询）；
  2. 解析频道里由旧 bot 发出的名单消息（回退方案）；
  3. 测试模式下手动注入假数据跑流程。
- **结算二次确认**（可选）：计票完成后先私下给管理员看结果，确认后才公示。
- **可视化配置面板**：频道、身份组、权重、通知等全部在 Discord 里点按钮配置，即改即生效，无需重启。
- **通知身份组**：自荐开放、投票开始时自动 @ 指定身份组。

### 🔧 通用能力

- 斜杠命令自动同步到指定服务器，启动即可用。
- 支持 HTTP 代理（国内网络环境可直接用 Clash 等代理连接 Discord）。
- 数据本地存储（SQLite + JSON），无需外部数据库。
- 完善的诊断日志：网络错误、限流、断线重连都有清晰提示。

### 🔄 分管身份组轮替

- 每个分管身份组可独立设置人数上限、每月问询时间、最低入服时长、冲突身份组以及多个通知/招募频道；目标支持频道、子区、论坛帖子和自动新建帖子的论坛父频道。
- 公开留任问询跨频道共享回答；未回答者和选择离任者在截止后自动卸任，Bot 不参与且不占名额。
- 空缺招募采用仅本人可见的二次确认，并在最终确认时实时复查资格与名额；招满后自动关闭所有频道按钮。
- `/呼唤蛙人` 允许管理员指定的蛙人身份组成员由 Bot 代理提及自己的身份组；默认每人冷却 60 秒，管理员可通过 `/分管轮替 设置蛙人冷却` 修改。

## 部署指南

### 1. 准备工作

- **Node.js 18 或更高版本**（建议 20+）
- 一个 Discord 账号，以及你要部署机器人的服务器（需要你有管理权限）

### 2. 创建 Discord 机器人应用

1. 打开 [Discord Developer Portal](https://discord.com/developers/applications)，点 **New Application** 创建应用。
2. 在 **General Information** 页记下 **Application ID**（后面填 `CLIENT_ID`）。
3. 进入 **Bot** 页：
   - 点 **Reset Token** 生成并复制 **Token**（后面填 `DISCORD_TOKEN`，只显示一次，注意保存）；
   - **必须打开这两个开关**（在 Privileged Gateway Intents 区域）：
     - ✅ **Server Members Intent**
     - ✅ **Message Content Intent**

     > 不开这两项机器人会启动失败或功能异常。
4. 邀请机器人进你的服务器：进入 **OAuth2 → URL Generator**，勾选 scopes 里的 `bot` 和 `applications.commands`，Bot Permissions 建议勾选：
   `View Channels`、`Send Messages`、`Embed Links`、`Attach Files`、`Create Public Threads`、`Send Messages in Threads`、`Mention Everyone`（用于 @ 通知身份组）。
   复制生成的链接在浏览器打开，选择你的服务器完成邀请。

### 3. 安装与配置

```bash
git clone <本仓库地址>
cd ManageBot
npm install
```

复制环境变量模板并填写（Windows 直接复制文件改名即可）：

```bash
cp .env.sample .env
```

打开 `.env`，**必填三项**：

```ini
DISCORD_TOKEN=你的机器人Token
CLIENT_ID=你的Application ID
GUILD_IDS=服务器ID          # 多个服务器用逗号分隔，如 123...,456...
```

> 服务器 ID 获取方法：Discord 设置 → 高级 → 打开「开发者模式」，然后右键服务器图标 → 「复制服务器 ID」。

**国内网络注意**：如果本机不能直连 Discord，在 `.env` 里加一行代理配置（以 Clash 默认端口为例）：

```ini
PROXY_URL=http://127.0.0.1:7890
```

其余可选配置（命令同步策略、健康日志、募选候选池 API 等）见 [.env.sample](.env.sample) 中的注释，均可留默认值。

### 4. 启动

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | **开发/试用**：直接运行 TS 源码，改代码自动重启 |
| `npm run build` | 编译到 `dist/` |
| `npm start` | **生产运行**：运行编译产物（需先 build） |
| `npm run console` | 打开通用本地管理控制台，可选择文字 TUI 或本机 HTML 控制面板 |
| `npm run typecheck` | 只做类型检查 |

看到 `🤖 机器人已完全启动` 即部署成功，此时斜杠命令已同步到 `GUILD_IDS` 里的服务器。

**生产环境建议**用 [pm2](https://pm2.keymetrics.io/) 之类的进程守护工具运行，并在 `.env` 中设置 `FATAL_EXIT_ON_EXCEPTION=true`，让机器人遇到严重错误时退出并由 pm2 自动拉起：

```bash
npm run build
pm2 start dist/core/index.js --name managebot
```

### 5. 数据存储与备份

所有数据保存在项目根目录的 `data/` 文件夹（首次运行自动创建）：

- `election.sqlite` — 募选模块全部数据（配置、候选池、场次、投票记录）
- `roleRotation.sqlite` — 分管轮替配置、场次、回答、成员同步与审计记录
- `messageCleanup.sqlite` — 本地内容维护任务、消息元数据索引及扫描进度
- `*.json` — 核心与模板模块的轻量设置

**备份 `data/` 目录即可备份全部数据**。迁移服务器时把它一起带走。

## 使用指南

### 通用命令

| 命令 | 说明 |
| --- | --- |
| `/ping` | 测试机器人是否在线 |
| `/调试-设置检查报告频道` | （管理员）设置系统报告发送到哪个频道 |
| `/分管轮替` | （管理员）配置和管理分管身份组轮替 |
| `/呼唤蛙人` | 蛙人身份组成员代理提及蛙人组 |

### 募选模块：从零开始跑一场募选

**谁能用管理命令**：服务器所有者、拥有 Administrator 权限的成员，以及配置面板里设置的「募选管理身份组」成员。

#### 第一步：配置（只需做一次）

运行 `/募选管理 配置` 打开配置面板，按分类点按钮设置：

- **📺 频道**：
  - *入口频道*（必设）——发布空位需求和自荐面板的地方；
  - *大众投票频道*——大众投票面板发到这里；
  - *结果公示频道*——当选名单公示到这里；
  - *管理内投频道*（可多选）——管理内部投票的讨论 thread 建在这里。
- **👥 身份组**：大众投票资格、管理投票资格、募选管理权限分别对应哪些身份组。
- **⚙️ 规则**：大众/管理投票开关、两者权重比、结算是否需要二次确认、并列时的判定规则。
- **🔔 通知**：自荐开放、投票开始时要 @ 的身份组。
- **🔗 候选池**：候选池 API 的地址/Token 等对接信息（也可在 `.env` 中配置），以及定时自动拉取开关。

所有改动即时保存，随时可以回来改。

#### 第二步：准备候选池

候选池决定了「谁有资格自荐」。用以下命令同步：

```
/募选管理 导入候选池
```

- 配置了候选池 API 时，直接从 API 拉取最新名单（发起募选时也会自动刷新一次，还可开启定时轮询）；
- 未配置 API 时，会回退解析当前频道里旧 bot 发出的名单消息。

用 `/募选管理 查看候选池` 随时核对在池名单。

#### 第三步：发起募选

```
/募选管理 发起 标题:社区管理员 空位数:2 自荐时长小时:24 投票时长小时:48
```

机器人会在入口频道发出自荐面板（并 @ 通知身份组）。之后**全自动**：

1. **自荐阶段**：候选池内成员点面板按钮、填自荐宣言报名；
2. **自荐截止** → 自动开启投票：大众投票面板发到大众投票频道，管理内投在管理频道建 thread；
3. 成员点「投票」按钮，在只有自己可见的菜单里选人（最多可选 = 空位数，可改票）；
4. **投票截止** → 自动结算：按权重合并大众/管理票数排名；
5. 若开了二次确认，管理员先看到结果、点确认后才公示；否则**直接公示**当选名单到结果频道。

#### 管理命令速查

| 子命令 | 作用 |
| --- | --- |
| `/募选管理 配置` | 打开配置面板 |
| `/募选管理 导入候选池` | 立即同步候选池 |
| `/募选管理 查看候选池` | 查看在池名单 |
| `/募选管理 发起` | 发起一场募选 |
| `/募选管理 列表` | 列出进行中的场次 |
| `/募选管理 查看报名` | 查看某场的自荐名单 |
| `/募选管理 开启投票` | 手动提前结束自荐、开启投票 |
| `/募选管理 结算` | 手动提前结算 |
| `/募选管理 公示` | 手动公示待确认的结果 |
| `/募选管理 取消` | 取消一场进行中的募选 |

> 「开启投票 / 结算」平时不需要手动执行——后台调度器到点会自动推进；这两个命令用于提前收尾或补救。

#### 测试模式（仅测试服使用）

在 `.env` 中设 `ELECTION_TEST_MODE=true` 并重启后，会多出 `/募选测试` 命令，可以凭空注入候选池、批量造自荐和模拟投票，不依赖真实 API 就能完整跑通流程。**生产环境务必保持 `false`。**

## 常见问题

**Q：启动报错「无法连接到 Discord」？**
这是网络问题不是 Token 问题。国内环境请在 `.env` 配置 `PROXY_URL` 指向本机代理（如 `http://127.0.0.1:7890`），并确认代理软件已启动、端口正确。

**Q：服务器里看不到斜杠命令？**
确认 `.env` 的 `GUILD_IDS` 包含该服务器 ID 且机器人已被邀请进服务器，然后重启机器人。如果列表里残留了旧命令，可临时设 `CLEAR_GLOBAL_COMMANDS=true` 启动一次清掉全局命令（Discord 侧生效可能延迟约 1 小时）。

**Q：点命令没反应、控制台也没日志？**
在 `.env` 设 `INTERACTION_DEBUG_LOG=true` 重启，即可看到每次交互的调试日志，便于定位。

**Q：想让某个身份组也能用管理命令？**
募选相关：在 `/募选管理 配置 → 👥 身份组` 里设置「募选管理权限」身份组。
通用管理命令：编辑 [permissionManager.ts](src/core/utils/permissionManager.ts) 顶部的 `ALLOWED_ROLE_IDS`。

## 项目结构与二次开发

```
src/
├── core/                        # 核心（与具体业务无关）
│   ├── index.ts                 # 主入口：创建客户端、注册命令、绑定事件、启动模块
│   ├── proxy.ts                 # HTTP 代理支持
│   ├── config/timeconfig.ts     # 通用时间/调度配置
│   ├── events/                  # 命令同步、交互分发、消息分发
│   └── utils/                   # 通用存储 / 权限判定 / 进度消息工具
├── shared/commands/             # 共享命令：ping、设置检查频道、调试权限
└── modules/
    ├── election/                # 🗳️ 募选模块（命令/交互组件/数据层/调度器）
    ├── roleRotation/            # 🔄 分管身份组月度轮替与补员
    └── template/                # 📦 模板模块：开发新模块时复制它
```

TypeScript 源码在 `src/`，编译产物输出到 `dist/`（已 gitignore）。

**开发新模块**：复制 `src/modules/template` 改名，然后在 `core/index.ts` 按文件内 ①②③ 标记接入即可。详细步骤见 [模板模块 README](src/modules/template/README.md)。
