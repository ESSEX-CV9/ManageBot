怎么测配好之后

1. 点「连通性自检」，用一条标准样例真调一次，看接口通不通、判得对不对。
2. 去单条测试或批量分析，凡是判成「需LLM定性」的， 下面都会出现一个「发起真实 LLM 判定」按钮。
3. 点了之后会真调接口，然后**按判定结果重算方案和通知**， 你能直接看到判定前后处置的变化。

TAG 互斥同一组里的 TAG，一个帖子只能挂一个

关键字互斥同一组里的分类，一条标题里只能出现一个

TAG 和标题关键字是两套独立的东西，互不互斥分开配。 同一对分类可以 TAG 互斥而关键字不互斥，反之亦然。

分类优先级数值大的优先保留。三种互斥撞上时都按它裁决

数值大的留下。TAG 互斥留 TAG、关键字互斥留词、交叉互斥则是输的那边被摘掉， 三种情况用的都是这一份优先级。

交叉互斥挂了某个 TAG，标题里就不许出现某类关键字

有方向，要双向禁就写两条。撞上时按上面的优先级裁决： 优先级低的那一边被摘掉——在 TAG 侧就摘 TAG，在关键字侧就删标题里的词； 两边都没配优先级时摘 TAG。
「挂百合 TAG 就不许标题里写百破」就是靠这条落地的，而百合和百破的**关键字**并不互斥。

分词词库纠正中文分词器的切分

标题正文里的命中必须落在词边界上才作数，所以分词器切错了判定就跟着错。
补词＝它不认识这个词（不补的话「我说纯爱牛逼」会切成「纯爱/牛/逼」，「纯爱牛」就混过去了）； 拆词＝它粘得太狠（「戴绿帽」被当成一个词，「绿帽」就抠不出来）。
标签区不过这道闸——那里是标签罗列不是句子。

词表分类词 / 黑名单 / 白名单 / 中性标记

词类型 分类组生效范围 替换为备注
分类词＝映射到某个分类，参与互斥判定。
黑名单＝命中就算违规，会被替换成「替换为」里填的词（留空则直接删掉）。
白名单＝明确「这不是分类标记」，用来吃掉误判。比如「拉拉队」会把里面的「拉拉」吃掉。
中性标记＝像「多路线」，不参与任何互斥判定，也不能豁免冲突。
